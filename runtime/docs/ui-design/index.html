四个客户端的主页面基准

四个客户端共用同一套内容层与同一份设计令牌，差异只在承载形式。下面四张卡片是各端主页面的实际页面，按 1440 与 1100 宽度渲染后等比缩小，点开即看完整尺寸。配色有暗色与亮色两套，右侧开关同时切换四张预览，每张卡片也可以单独切换用来对比。

风格基准 Web 主页面 桌面端主页面 移动端主页面 命令行主页面
01

画布退后，内容在前

面板之间靠 1px 线条与四级明度差区分，不用阴影与卡片堆叠。对话流、工具输出与文件预览是视觉主体。

02

品牌色只标注意图

蓝色只出现在主行动点、当前选中项、品牌标记与需要用户决定的位置；状态交给成功、警告、危险三色。

03

状态先于装饰

加载、空、失败、只读、离线、待处理、权限不足、已停用、降级九种状态各有固定版式与位置，容器尺寸不随数据到达而跳动。

命令行

终端场景

复用 dsh-tui 的准入协议与贡献点，把控制平面接成渠道。全部状态用文字与色块表达，不依赖图形组件。

  • 场景页签承载会话、审批、项目与设置，审批页签带待处理计数
  • 工具调用按行铺开，成功、运行中、失败用前缀与颜色区分
  • 审批以带左侧色条的块呈现，数字键作答，状态栏常驻
命令树·面板与徽标·非交互与 ACP 接入 暗色

需要确认的四项 REVIEW

01 配色基调 暗色为默认，亮色是同一语义的对应取值，切换只换取值不换映射：画布、面板、线条、文字、品牌、状态各自保持原有职责。亮色下的辅助文字与极弱文字已按对比度下限重新取值。
02 信息密度 正文 13px、行高 1.6、列表行 34px、会话头部 54px、左侧栏 268px、右侧栏 428px。长时间会话在 1440 宽度下同屏可见对话、审批与预览。
03 识别标记 面板顶部 2px 品牌色细条标出当前焦点区域，左侧会话列表用 2px 竖条标出当前会话，两处标记在四端与两套配色里保持一致。
04 四端差异方式 Web 关闭网页页签；桌面补回网页页签并承载桌面控制；移动端用抽屉承载接管与导航；命令行用文字块与色条重建全部状态。
