命令行场景、命令树与非交互

命令行沿用终端的表达方式：场景页签承载会话、审批、设置与面板，命令树给出全部命令与参数，非交互模式输出结构化事件，ACP 接入复用同一份场景定义。

四类场景 命令树 非交互 JSON ACP
终端里没有图形组件。状态用文字与颜色表达，进度用行内计数，审批用带左侧色条的块。最小可用宽度 80 列，低于 80 列时命令提示折行。

非交互输出与 ACP

CLI-13 · CLI-14JSON · 退出码 · 会话

非交互模式按行输出结构化事件，退出码表达结果类别。ACP 接入把同一份场景定义暴露给外部编辑器，事件字段与非交互一致。

非交互输出状态 · 流式事件

每行一个 JSON 对象，事件字段与非交互文档一致；不带颜色与控制字符。
退出码状态 · 五种结果
0回合完成，无待处理项成功
1模型或工具返回失败失败
2参数非法或命令不存在用法错误
3存在待作答的审批或提问需处理
75控制平面不可达，进入仅本地暂时失败
退出码写进脚本可判断的位置，不依赖输出文本解析。
