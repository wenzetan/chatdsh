定时任务、自动化、MCP 注册表与额度

四类运维页面共用表格与列表两种版式。定时任务与自动化按记录行呈现，注册表按设备分组，额度页给出上限、已用与拒绝原因。

四组能力 cron 与 webhook 按设备端点 额度与拒绝原因
运维页面的三条统一规则：失败行保留并给出错误码；停用或未接线处如实标注，不做假成功；危险动作（取消、删除、撤销）写影响范围。

生成的加载器行文本 · 可复制
mcp.toml复制
[[server]] name = "files" command = "npx" args = ["-y", "@modelcontextprotocol/server-filesystem"] env = { FILES_ROOT = "${FILES_ROOT}" } [[server]] name = "search" url = "http://127.0.0.1:8765/mcp" token_env = "SEARCH_TOKEN"
加载器行只写环境变量名，不写凭据值；停用连接器后需要刷新注册表才会消失。
生成的行与该设备的端点一一对应，可直接粘贴到运行时的加载器配置。
