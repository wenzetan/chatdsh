# 参考页面目录

`pages/` 下的页面是补充页面，覆盖设置、身份、控制平面、原生窗口、命令行与状态版式。四端主页面在上一级目录。

## 页面构成约定

每个页面遵循同一骨架，保证审阅时位置固定：

- `<head>` 依次引用 `../tokens.css`、`../app.css`、`../pages.css`，`<body data-color-scheme="dark">`，结尾引用 `../scheme.js`。
- 页面顶部 `.plate-hd`：`.top` 放返回目录链接与页面编号，`h1` 写页面名称，`.lead` 写这一页覆盖的范围，`.tags` 放状态徽标。
- 正文按 `.sect` 分段，每段一个主题；样张放 `.demo`，头部 `.demo-hd` 写组件名与状态标签，底部 `.demo-cap` 写行为说明。
- 同一段内的多个状态并排放在 `.grid2` 或 `.state-grid` 里，标签统一写「状态 · 加载中」这类形式。

## 样式来源

| 文件 | 用途 |
|---|---|
| `../tokens.css` | 设计令牌，两套配色 |
| `../app.css` | 产品界面组件：侧栏、会话、工具卡片、接管卡片、输入区、状态条 |
| `../pages.css` | 参考页版式：页面骨架、设置外壳、表单、表格、对话框、文件树、终端、原生窗口、移动端、命令行画布、页面目录 |

颜色、字号、间距、圆角只引用令牌，页面内不写颜色字面值。页面专用的少量布局写在该页 `<style>` 里，命名以页面前缀开头，例如 `.login-card`。

## 配色

页面地址带 `?scheme=light` 为亮色，其余为暗色。页面自身不提供配色开关，切换由审阅入口统一控制。
