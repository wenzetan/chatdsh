桌面端原生部件

桌面壳的原生部分：应用菜单、托盘菜单与徽标、更新与校验、安全模式与启动失败恢复、崩溃证据、系统权限向导、桌面控制确认。

Windows x64 优先 更新与回滚 安全模式 权限向导
原生部件保持系统观感。菜单与托盘使用系统字体与系统阴影，尺寸与系统一致；只有弹窗内的内容区沿用应用令牌。危险动作在系统弹窗里也写明影响范围。
