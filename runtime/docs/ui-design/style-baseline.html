ChatDSH 客户端界面风格基准

界面服务于长时间运行的 agent 会话：信息密度高、状态多，同一屏里同时存在对话、工具输出与文件预览。视觉基调因此选择低饱和深色画布、单一品牌强调与清晰的层级线条，让界面让位于内容。

深色为默认 明亮对照 颜色全部来自令牌 正文 13px 紧凑密度

风格主张 STANCE

三条约束决定所有界面的观感，四个客户端与全部业务面板共用同一套判断。

01

画布退后，内容在前

面板之间靠 1px 线条与四级明度差区分，不用大面积阴影与卡片堆叠。对话流与工具输出是视觉主体，容器只提供边界。

02

品牌色只标注意图

蓝色只出现在主行动点、当前选中项、品牌标记与需要用户决定的位置。状态一律交给成功、警告、危险三色。

03

状态先于装饰

加载、空、失败、只读、离线、待处理、权限不足、已停用、降级九种状态各有固定版式与位置，容器尺寸不随数据到达而跳动。

颜色令牌 TOKENS

色值与 runtime/docs/theme-plugin-contract.md 的标准化令牌一一对应，右侧取值为当前配色下的实际值，切换配色会同步更新。

字体层级 TYPE

界面使用系统无衬线字体，中文优先 PingFang SC 与思源黑体，代码使用系统等宽字体。正文 13px 是长时间阅读的下限，标题与正文只差两级，避免界面被大字号撑散。

间距与圆角 SCALE

间距取 4 的倍数，界面主节奏是 8 与 12。圆角控制在 5 到 11 像素：控件 5、卡片 8 到 11、弹层 16，不使用超大圆角与胶囊形大面积容器。

状态表达 STATES

九种全局状态使用固定版式。列表页用骨架行，详情页用骨架块，表单页禁用控件，对话页用增量占位；空状态必须给出下一步动作。

动效与适配 MOTION

动效只服务于状态变化：120ms 用于悬停与按下，200ms 用于面板展开与页签切换，曲线统一为 cubic-bezier(.24,.72,.32,1)。系统开启减少动态效果时全部关闭。

快捷键与图标kbd · icon
⌘K 命令面板 / 斜杠命令 @ 引用源与技能 图标为 1.5px 描边线性图形，16px 网格，不填充

界面签名

面板顶部 2px 品牌色细条标出当前获得焦点的区域，左侧列表用 2px 竖条标出当前会话。这两处标记与品牌主按钮构成识别锚点，出现在全部客户端。
