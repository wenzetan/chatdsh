### WP04 设备实时通道与前缀路由

[设备链路](<../gateway/src/device-link.ts>)扩展为协议版本 2 的通道化帧协议：握手携带版本、设备标识与代次，`welcome` 下发通道数、发送缓冲、通道 credit、数据帧与消息大小五项预算；通道状态为 opening → active → half-closed → closed，未知通道、序号跳跃或重复、超额发送立即 reset 该通道；同设备新代次替换旧连接并按 4000/replaced 关闭；背压超限只终止受阻通道，其他通道照常完成；取消沿通道传播并在设备确认后停止投递；重复事件按标识去重且额度照常补回。前缀路径校验只接受以单个斜杠开始的相对路径，拒绝完整 URL、`//`、路径穿越与编码越界。[WebSocket 层](<../gateway/src/websocket.ts>)补齐帧编解码与背压所需的缓冲与关闭语义。

[验收测试](<../e2e/unit/client-complete-wp04-handshake.test.mjs>)共 19 项，全部通过：全部断言运行在真实控制平面与真实 WebSocket 升级上，设备侧是真实版本 2 帧客户端。

### WP09-A 项目、助手、制品、连接器与技能宿主
