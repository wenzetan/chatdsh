# 客户端界面的验证记录

界面基础设计的实现分三层：主题插件负责令牌与样式注入，共享组件包负责面板元件，十二个客户端面板负责内容。下面每条检查都在仓库根执行，结论来自实际运行。

## 主题与配色

```bash
node scripts/verify-theme-ui.mjs
```

在真实 Chrome 里打开首屏，断言主题样式节点已挂载、令牌解析为设计取值、上游 `--dsw-alias-bg-base` 已映射到本设计画布、两套配色能随 `data-ds-dark-theme` 来回切换。

## 对比度

```bash
node scripts/check-ui-contrast.mjs
```

按设计稿 2.3 节核对十五组配色配对。两套配色共三十项，全部达到三档下限（标题 7:1、正文与按钮 4.5:1、辅助与状态 3:1），并与设计稿记录的实测值相差不超过 0.6。取值漂移会被拦下。

## 组件样式只引用令牌

```bash
node scripts/check-ui-kit-tokens.mjs
```

核对约束 5。组件样式引用的三十二个自定义属性全部有定义，来源是主题令牌、别名映射，或组件样式自身由令牌算出的派生声明（实测主题与组件共定义一百三十九个）；样式里不出现十六进制与 rgb 族颜色字面值；组件样式确实随主题一起注入文档。

## 动效

```bash
node scripts/check-ui-motion.mjs
```

核对设计稿第六节。三个动效令牌取值为 120 毫秒、200 毫秒与 `cubic-bezier(0.24, 0.72, 0.32, 1)`；组件过渡引用这两个时长与曲线，没有写死时长；减少动效分支把动画与过渡都压到 0.001 毫秒。

## 骨架与真实行等高

```bash
node scripts/measure-panel-rows.mjs
```

核对状态覆盖里「骨架行与真实行等高」。在真实运行时页面注入与组件产出一致的 DOM，量取两行内容的行、单行内容的行、以及骨架行的单行高度和行距：

| 组 | 单行高度 | 行距 |
|---|---|---|
| 两行内容的行 | 62 | 64 |
| 单行内容的行 | 62 | 64 |
| 骨架 | 62 | 64 |

四组齐平，数据到达时面板不产生位移。行高由面板上的 `--chdsh-row-h` 统一给出，取值为 `calc(13 × 1.6 + 12 × 1.6 + 22px)`，即标题行、间隙、副行、内边距与边框之和；两行内容的行、单行内容的行与骨架都按它对齐。

## 遥测链路

```bash
node scripts/verify-telemetry-flow.mjs
```

在已登录页面里依次打状态、自检、中继三个端点。本机实测：状态端点 200，开关打开，出口 `http://127.0.0.1:5080`；自检 200 并返回探针标识；中继 503 `credential-missing`。也就是说客户端事件能到宿主、宿主能解析并路由，卡在导出凭据未配置。单独观察页面加载即可看到一次中继尝试，说明主题插件在安装时确实发出了上报。中继只转发不解析，客户端载荷里的属性不会被它丢弃。

### 自动断言项

1. 可访问名称与角色：axe-core 4.12.1 全页检查，严重与致命问题为零；对比度结果单独记录。Chrome 可访问树用于核对角色与名称：按钮与输入都有名称，跳转链接、对话框、主区域与侧栏出现在树里。
2. 键盘路径：从 `body` 连续按 Tab 遍历，焦点顺序与文档顺序一致，可见可聚焦元素全部可达。命令面板支持 Ctrl+K 打开、方向键、Home、End、Enter 与 Escape。
3. 焦点恢复：命令面板关闭后焦点回到触发控件；项目面板的对话框把焦点约束在内部，Escape 关闭后焦点回到项目面板。
4. 逐元素横向溢出：对场景内每个可见元素取 `getBoundingClientRect` 与计算样式，与视口宽度比较，滚动容器内部的横向滚动单独放行。页面级 `scrollWidth` 与 `clientWidth` 同步断言。
5. 触控目标尺寸：按钮、链接、输入、选择器与 `role` 按钮逐项量取；44 × 44 作为设计目标，24 × 24 作为机器判定下限，介于两者之间的目标记入缺口清单。
6. 200% 文字缩放：根字号改为 32 像素后重跑溢出与触控断言；768 与 1440 宽度下逐元素无横向溢出，320 宽度下侧栏以外没有元素被裁切，全部动作能通过页面滚动到达。
7. 系统级状态播报：列表容器在读取期间声明 `aria-busy`，完成后取消；状态区域使用 `role=status` 与 `aria-live=polite`；失败说明以文本呈现。
8. 只读校验：只读读取前后比对真实存储的会话记录数量与写接口调用次数，两者都不变化。

### 真实状态触发

- 控制平面失败与恢复：前置服务把到真实控制平面的转发关闭，返回 503，界面给出带错误码的失败说明；恢复转发后重新读取成功。
- 断网：`agent-browser set offline on` 真实关闭网络，点刷新后读取失败并显示说明；恢复网络后需要用户再次操作，界面没有自动重发请求。
- 读取延迟：前置服务对真实宿主服务请求加 1200 毫秒延迟，读取期间出现骨架并声明 `aria-busy`，读取完成后骨架消失。
- 宿主服务拒绝：面板请求返回 503 后，制品、项目、助手与技能、连接器面板给出失败与重试说明；恢复后重新读取成功。
- 空结果：删除真实服务里的记录后重新挂载，面板显示空状态，可交互元素仍有名称，无横向溢出。

### 实测发现

1. 触控目标尺寸（已修复）：外壳的检索输入、跳转链接、分组与设备选择器、对话框按钮原先为 29.4 至 36 CSS 像素，低于 44 × 44 的设计要求。已在 `shell.css` 为可交互元素统一加 `min-height: 44px`（按钮类另加 `min-width: 44px` 与 flex 居中），隐藏元素的 `[hidden]` 规则同步保留。复跑外壳与面板矩阵测试，触控目标全部达到 44 × 44。
2. 窄屏叠加文字缩放（已修复）：200% 文字缩放与 320 宽度同时成立时，外壳侧栏 `min-width: 16rem` 在 32 像素根字号下为 512 像素，页面出现 192 像素的横向滚动。已在窄屏媒体查询把侧栏 `min-width` 与宽度收到 `100%`，页面不再横向滚动。
3. 制品面板空状态（已修复）：空状态没有 `role=status` 播报区域。已把 `ui-kit` 的 `EmptyState` 组件统一加上 `role="status"` 与 `aria-live="polite"`，全部使用该组件的面板因此获得播报区域。
4. 连接器面板失败说明（已修复）：宿主服务拒绝时渲染配置与凭据说明而没有可见失败说明。已在面板失败分支渲染 `ErrorNote` 与重试入口。
5. axe 的 `color-contrast` 结果单独归档，不进入严重问题门槛；配色对比度由 `scripts/check-ui-contrast.mjs` 逐对实测。

### 未完成项

- 权限拒绝（麦克风、通知）没有触发：录音区需要 workspace-tools 的附件与语音数据入口，通知中心需要通知路由，两者在本轮矩阵里没有挂载。
- `revision` 冲突没有触发：需要面板的可写路径与第二个客户端的并发提交，本轮只挂载了读取路径。
- 内容超限没有触发：需要超限字段的界面提交，例如助手指令上限与消息长度上限。
- 服务退出没有做进程级终止：本轮用前置转发关闭响应 503 覆盖失败与恢复路径，真实进程终止留待补齐。
