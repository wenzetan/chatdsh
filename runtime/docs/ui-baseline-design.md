# 客户端界面基础设计方案

本文件定义界面基础令牌与组件尺度。完整客户端目标以[完整交互规格](<client-complete-spec.md>)和[完整设计稿](<ui-design/complete.html>)为准，实施任务与验收见[工作包](<implementation-work-packages.md>)。完整设计稿覆盖 S01–S32、暗色/亮色/高对比度、全部通用状态与各端页面。原有[参考页面](<ui-design/>)保留基础组件样张职责，业务交互使用完整设计稿的明确规则。

## 一、风格主张

| 主张 | 具体做法 |
|---|---|
| 画布退后，内容在前 | 面板之间靠 1px 线条与四级明度差分层，不使用大面积阴影与卡片堆叠；对话流、工具输出、文件预览占据视觉主体 |
| 品牌色只标注意图 | 品牌蓝只出现在主行动点、当前选中项、品牌标记与需要用户决定的位置；状态含义一律交给成功、警告、危险三色 |
| 状态先于装饰 | 十种状态与长任务各有固定版式与位置；占位高度与真实内容一致，数据到达时不产生位移；空状态必须给出下一步动作 |

### 2.4 配色切换

- 基础样张在 `body` 上使用 `data-color-scheme="dark|light"`。完整设计稿提供 `dark|light|contrast`，目标产品还支持跟随系统与 `forced-colors`。
- `:root` 声明 `color-scheme: dark`，亮色 body 声明 `color-scheme: light`，让滚动条、输入框等原生部件跟随配色。
- 切换配色只改变 `data-color-scheme`，不切换组件分支，不改变任何尺寸与布局。
- 参考页面用地址参数选择配色：`?scheme=light` 为亮色，其余为暗色；审阅入口页提供全局开关与单张卡片的开关。

## 三、字号与排版

界面使用系统无衬线字体，中文优先 PingFang SC 与思源黑体；代码、路径、标识使用系统等宽字体并关闭连字。正文 13px 是长时间阅读的下限，标题与正文只差两级，避免界面被大字号撑散。

| 角色 | 字号 / 行高 / 字重 | 补充 |
|---|---|---|
| 页面标题 | 26 / 1.25 / 640 | 字距 -0.02em |
| 区块标题 | 20 / 1.3 / 620 | 字距 -0.01em |
| 卡片标题 | 16 / 1.35 / 600 | — |
| 强调正文 | 14 / 1.6 / 460 | — |
| 正文 | 13 / 1.6 / 400 | 默认字号 |
| 辅助 | 12 / 1.55 / 400 | 时间、来源、计数 |
| 标签 | 11 / 1.45 / 600 | 大写，字距 0.06em |
| 等宽 | 12 / 1.6 | 代码、路径、接口名 |

## 四、尺度

### 4.1 间距

序列为 4、8、12、16、20、24、32、40。界面主节奏是 8 与 12：面板内边距 10 到 20，卡片内边距 8 到 16，区块间距 14 到 22，页面级间距 26 到 44。

### 4.2 圆角

控件 5，列表项与小组件 8，卡片与接管卡 11，弹层与抽屉 16。胶囊形只用于徽标、状态点与进度条，不用作大面积容器。

### 4.3 基础样张结构尺寸

下表保留基础样张尺度。目标图形客户端的完整操作区域至少 44×44 CSS 像素；图标和装饰尺寸可以较小，操作区域必须达到目标下限。响应式、文字缩放和实际画板尺寸按第十一节及[完整客户端规格](<client-complete-spec.md>)第三节执行。

| 部位 | 基础样张尺寸 |
|---|---|
| 左侧栏 | 268，折叠态 60 |
| 右侧停靠栏 | 428 |
| 会话头部 | 54 |
| 底部状态条 | 30 |
| 列表行 | 34 |
| 桌面触控目标 | 34 |
| 移动端触控目标 | 44 |
| 窗口标题栏 | 32 |
| 命令行页签条 | 34 |
| 命令行状态栏 | 30 |

### 4.4 层级手法

面板分层用背景明度，不用阴影；浮层用一层柔和投影加 1px 边框；危险动作用左侧 2px 实色条标注；不使用渐变、玻璃模糊与发光。

## 六、识别标记与动效

两处标记在四端与两套配色中保持一致：当前获得焦点的面板在顶部有 2px 品牌色细条；会话列表中当前会话左侧有 2px 品牌色竖条。品牌主按钮是第三处识别点，三者共同构成界面签名。

动效只服务于状态变化：120ms 用于悬停与按下，200ms 用于面板展开与页签切换；曲线统一为 `cubic-bezier(0.24, 0.72, 0.32, 1)`。系统开启减少动态效果时，全部动画与过渡降到 0.001ms。

## 七、四端主页面

Web、PWA、桌面共用语义令牌与内容层，命令行通过宿主贡献点提供本机交互。以下页面结构承接基础样张，目标页面与状态以[完整客户端规格](<client-complete-spec.md>)S01–S32为准；图形客户端在每个窗口中保留一个活动设备 iframe，访问认证不建立账号表。

### 7.1 Web 端

外壳是浏览器窗口，顶部 38px 为地址条，内容是三栏加底部状态条。

- 左侧栏 268px，自上而下是品牌标记与名称、工作区选择（高 44，带在线点）、新建会话主按钮（高 34）、会话检索（高 30，带快捷键提示）、按时间分组的会话列表、业务面板入口（项目、上下文占用）、底部设备、访问与连接状态。
- 中栏自上而下是目标条（高 32，目标文字、进度条、步数、清除入口）、会话头部（标题、设备在线状态、头部动作、工作区与来源设备、模型与权限档位、preset）、对话流（回合条、用户消息、助手消息、工具卡片、产出卡片）、消息队列条、输入区。
- 输入区与接管卡片占用同一位置。等待审批时该位置是审批卡片：工具调用与命令、原因说明、宿主支持的动作按钮、权限范围与失效说明。同一时刻只显示一张接管卡片。
- 右侧栏 428px，页签依次是文档预览、文件、终端、网页。「网页」在 Web 形态为关闭态并标注由桌面端补回。文档预览含路径条、只读徽标、行号与语法着色的内容区、底部编码与打开方式。
- 底部状态条承载连接、模型、上下文占用、待处理审批数、目标设备状态、命令快捷键与版本。

### 7.2 桌面端

外壳是原生窗口：顶部 32px 标题栏含菜单、标题与窗口控件，其下 34px 是桌面控制常驻指示条，内容同样是三栏加状态条。

- 桌面控制指示条左侧 2px `warn` 条与状态点，正文给出目标应用与两项系统授权，右侧是已运行时长、授权有效期与「中断」危险按钮。
- 左侧栏与 Web 端一致，按工作区显示名聚合全部设备目录，展开后显示设备与路径，会话行标注来源设备。
- 中栏会话头部显示目标执行设备与目录；本机目录可以调用原生选择器，远程目录通过目标设备列举。输入区受目标设备在线状态与接管状态约束，离线时保留可编辑草稿并明确拒绝发送。
- 右侧栏补回「网页」页签并作为默认页签：地址条带沙箱徽标，内容区是控制平面诊断页的读数卡片。
- 底部状态条额外承载保活状态、托盘状态与更新通道。

### 7.3 移动端

参考页面并排给出两屏，屏宽 390、屏高 790，外层是设备边框与说明文字。

- 会话页：顶部 26px 系统状态栏、52px 会话与设备标题栏（返回、标题与副标题、分享、更多）、元信息行（模型、权限、preset、上下文）、对话流、上传提示条、输入区、18px 手势条。输入区图标按钮与发送按钮均为 44×44。
- 审批接管页：同一会话与设备标题栏与元信息行，对话流下方是底部抽屉。抽屉含把手、标题行（等待审批徽标、标题、倒计时）、命令块、原因说明、四个等宽 44px 高的动作按钮。
- 抽屉替换输入区，不并列显示输入框与接管卡片。离线时审批提交明确失败并保留卡片；消息只保留草稿，恢复连接后由用户手动发送。在线执行中的消息队列失联后暂停，恢复后由用户确认处理。

### 7.4 命令行

终端全屏：顶部 34px 页签条，中间是场景内容，底部 30px 状态栏。

- 页签条承载会话、审批、项目、设置四个场景，审批页签带待处理计数徽标；右端列出上下文占用、队列长度与面板快捷键。
- 会话场景按行铺开：会话标题行与元信息行、用户输入行、助手正文行、工具调用行（成功 ✓、运行中 ⚠、失败 ✗ 前缀加颜色区分）、产出说明行。
- 审批以带左侧 2px `warn` 条的块呈现：标题、命令、原因、四个带编号的选项、按键提示。
- 队列行与输入行紧随其后，输入行左侧是提示符与光标块。
- 状态栏分段呈现连接状态、模型、上下文占比、待审批数、队列长度、工作区与版本。

## 八、状态覆盖

十种状态与长任务在四类页面上的落点如下。每一行的版式固定，容器尺寸不随数据到达变化。

| 状态 | 列表页 | 详情页 | 表单页 | 对话页 |
|---|---|---|---|---|
| 加载中 | 骨架行与真实行等高 | 骨架块保留标题 | 控件禁用 | 增量占位，等待首字时保留输入区 |
| 空 | 空状态说明加下一步动作按钮 | 记录不存在说明加返回 | 填入默认值 | 欢迎语加选项卡片 |
| 失败 | 重试按钮，保留其他可用区域 | 重试与返回并列出读取失败的接口 | 保留已填内容加错误摘要 | 错误卡片加重试，回合条标注失败 |
| 只读 | 不出现编辑入口 | 只读徽标加元数据 | 不适用 | 输入区替换为说明，不显示可编辑控件 |
| 离线 | 显示已保存数据与读取时间 | 已保存数据与时间 | 禁止提交并保留输入 | 明确拒绝发送，保留可编辑草稿 |
| 待处理 | 计数徽标 | 处理按钮 | 不适用 | 审批或提问接管卡片 |
| 权限不足 | 说明缺少的权限与申请入口 | 同上 | 控件禁用并说明原因 | 工具失败卡片说明缺少的权限 |
| 已停用 | 状态标记 | 状态标记与原因 | 控件禁用 | 能力不可见并说明由哪一端提供 |
| 危险动作 | 确认弹窗写明影响范围 | 确认弹窗 | 二次确认 | 审批卡片 |
| 降级 | 降级徽标与降级时间 | 最近一次读数与时间 | 禁用保存 | 系统提示条 |
| 长任务 | 进度与取消 | 步骤时间线 | 不适用 | 回合进度条与停止按钮 |

## 九、固定约束

1. 输入区与接管卡片的接管关系由 `conversation.composer` 的优先级决定，同一时刻只显示一张接管卡片。
2. agent preset 只能在空白会话里切换，已有回合的会话不显示换档入口。
3. 业务设置区段按注册顺序排列，新增区段不覆盖上游设置页。
4. 右侧栏页签按类型唯一，同一类型再次打开时切换到已有页签。
5. 所有颜色、字号、间距、圆角引用令牌，业务组件不写颜色字面值。
6. 配色切换只改变 `data-color-scheme`，不改变尺寸与布局。
7. 所有图形客户端操作目标至少 44×44 CSS 像素；PWA 输入区避让系统栏与输入法。
8. 只读快照不显示输入框。跨设备会话提供在远程继续与在本机继续；源设备离线时发送失败，本机继续通过 fork 创建新会话。
9. 审批在离线时明确拒绝并保留卡片，不进入队列。
10. 分享快照是固定内容，界面不提供继续对话或编辑入口。
11. 敏感信息只显示环境变量名、掩码或状态，不显示凭据原文。
12. 状态占位与真实内容等高，数据到达时不产生位移。

### 10.2 验证方式

基础样张与完整产品稿分别记录测量结果。完整稿使用无头浏览器的 DOM、可访问树和计算样式检查 S01–S32，真实业务验收遵循[完整客户端规格](<client-complete-spec.md>)AC-G01–G12；不使用视觉截图代替测量：

- 页面无控制台错误，样式表与脚本全部加载成功。
- 320、360、390、768、1024、1280、1440 CSS 像素下页面正文无横向溢出，代码、宽表格和终端使用独立滚动区域。
- 左侧栏 268、右侧栏 428、状态条 30 与令牌取值一致。
- 对话流各行按内容高度排版并独立滚动，不出现被压缩的块。
- 图形客户端操作区域至少 44×44 CSS 像素，文字缩放、软键盘与安全区不遮挡主动作。
- 暗色、亮色、高对比度和系统强制配色满足第十一节目标；正文及状态文字至少 4.5:1、重要标题至少 7:1、控件边界与焦点至少 3:1。
- 配色切换后令牌取值同步更新，且能切回原配色。
- 审阅入口与页面目录切换配色时，链接与预览框的内部配色同步切换。
- 基础样张按其配色声明核对令牌解析；完整稿 S01–S32 按所选配色、画板和适用状态核对布局、焦点和可用动作。基础样张通过不代表产品业务完成。

## 十一、覆盖范围

基础样张覆盖两套配色原值、字号与尺度、组件排版、四端结构及通用状态容器。产品目标范围由完整交互规格与完整设计稿定义，实际实现状态由[功能清单](<ui-feature-inventory.md>)和[验收状态](<acceptance.md>)记录。

完整界面范围见[完整交互规格](<client-complete-spec.md>)的 S01–S32 与 AC-G01–G12；命令面板、引导、通知、输入引用、查看器、第二窗口、导出与无障碍均具有对应画板和验收条件。

完整设计稿使用以下可访问性修订：所有图形操作目标至少 44×44 CSS 像素；普通文字和状态正文对比度至少 4.5:1，标题至少 7:1，控件边界和焦点至少 3:1。亮色状态文字使用 `ok #147345`、`warn #825600`、`danger #B52632`、辅助文字使用 `faint #595F6B`，强边框使用 `#737C8C`；暗色强边框使用 `#747B89`。高对比度以完整设计稿的令牌块为准。实现时由 WP02 将这些目标值统一登记到主题令牌，禁止业务组件独立定义颜色。

完整稿的窄屏断点为 768 CSS 像素；画板宽度选择代表最大内容宽度，受当前浏览器可用宽度限制。精确尺寸验证通过真实视口测量执行。设计稿中的画板并列展示同场景的多个界面状态，真实产品按交互规格逐步进入对应页面。
